서비스 아이디어 및 기획, 데이터베이스 설계, Gemini API 연동, 진단·학습 노트·마이페이지·배지 관련 REST API 개발, AWS 배포 및 일부 화면 개발

#### 주요 서비스 기능

- **AI 코드 진단:** 제출한 코드를 4가지 평가 기준으로 분석하고 항목별 점수·분석 근거·개선 코드 제공
- **맞춤 학습:** 진단 결과를 활용한 빈칸 학습 및 힌트 제공
- **학습 기록:** 진단 이력 조회·복원, 학습 노트 작성, 태그·즐겨찾기 관리
- **성장 관리:** 활동 통계, 연속 학습 일수, 배지를 통한 학습 현황 확인

기본 농장 시스템에 작물 진화, 도감 수집, 아이템 거래 및 퀘스트를 연결하여 게임 진행에 따른 성장과 수집 요소를 제공했습니다.

인벤토리, 도감, 연구소, 상점, 공통 UI, Firebase 기반 데이터 저장·복원 및 팀원 간 기능 통합

- **상점 및 퀘스트:** 아이템 구매·판매, 메인·서브·일일 퀘스트 진행
- **진행 저장:** 게임 진행 데이터 저장 및 재실행 시 복원
