### 🐾 Howsu — 가족 공동 반려동물 케어 앱

**Kotlin / Jetpack Compose · Firebase Auth · Firestore · Cloud Functions · FCM**

> 가족 구성원이 돌봄 할 일과 일정을 공유하고, 실시간 알림으로 반려동물 케어를 함께 관리하는 Android 앱입니다.

**내가 해결한 핵심 문제**

- **다중 소셜 로그인 통합:** Kakao·Naver·Google 로그인과 Firebase 인증 연결, Custom Token 인증 흐름 구현
- **공유 데이터 정합성:** 가족 그룹 가입·탈퇴와 반복 일정 변경에 Firestore Batch 적용
- **이벤트 기반 알림:** Cloud Functions + FCM과 AlarmManager를 활용해 담당자 알림 및 로컬 미리 알림 구현
- **화면 상태 동기화:** StateFlow·SavedStateHandle로 인증 상태 및 수정 후 목록 새로고침 관리
